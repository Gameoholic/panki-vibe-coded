# Word audio from Forvo

> **Scope of this file.** Word audio from Forvo, called by Panki's server.

- **The server calls Forvo, nothing else does** (`apps/api/src/forvo.ts`, `routes/forvo.ts`). The extension never holds the key or names an address: it asks Panki for a word's recordings and for one by its id among them. The key is everyone's (`shared.sqlite` → `service_keys`, set by an admin), or else the server's (`PANKI_FORVO_KEY`); it goes only into Forvo's own request addresses, never into a log or an answer (`ForvoStatus` says only whose it is). No key is `409`.
- **Kept for everyone, on disk, for good.** Forvo's terms say not to keep copies; Panki keeps them anyway, deliberately: the one paying is the only listener, and it spares Forvo a request at every play. The first ask for a word fetches its list and, at once, its best liked recordings (`KEPT_PER_WORD`), because the list's links last two hours and one fetched later would need the list again. The list as kept (`forvo_words`, only the recordings that came; a word with none kept as none) and each recording (`forvo_recordings`: bytes, who said it, who asked first) answer every later ask by anyone. There is no memory cache; the shared store is the cache. A word's first ask costs up to nine of the day's 500 requests; a word asked before costs none.
- **Picking one copies it into the account's files** (`media` and the account's own `forvo_recordings` row), so a card names its own account's file and an account's cards, storage and backups stay whole on their own. The same recording picked again is the same file. A recording kept but not added stays a file of the account. Recordings accounts held before the shared store are copied in at every start that finds one missing (`shared.ts` → `gatherForvoRecordings`).
- **What's believed of Forvo:** its answer's shape isn't documented, so each recording is read through the contracts' `ForvoItem` on its own; a file is fetched only from an https `forvo.com` address and must come back from one, at most 2 MB, opening as an mp3 (`sniffMimes`, as any upload).
- **Into the drawer** (`roles.ts` → `forvoAudio`, into a field that takes sound; `ui/Panel.tsx` → `voiceBlock`). Once the dictionaries have answered, the word as the dictionary writes it (or as typed) is asked of Panki (`messages.ts` → `askVoices`), the best rated taken (`askVoice`, its bytes to the page as base64) and heard with the app's `MediaView`; a `Dropdown` picks another; "Pronunciations by Forvo" and who said it stand under it, as Forvo's terms require. The file's id is the field's value from the start (`valuesFor`), so the card is made with it, a Required field included, and nothing follows the card.
- **In the app**: Settings → Admin → Word audio (`views/SettingsView.tsx` → `WordAudioSection`, `routes/wordAudio.ts`), a Source over the contracts' `WORD_AUDIO_SOURCES` (Forvo alone, so disabled), then its `KeyPanel`.
