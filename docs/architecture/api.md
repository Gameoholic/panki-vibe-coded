# API surface

> **Scope of this file.** The API surface: its routes, what each takes and answers.

All JSON, but for a file's own bytes (the two `/api/media` routes). Validation at the boundary with the shared Zod schemas; a failed parse is `400 { error: { message, path } }`. Unknown `/api/*` is `404`. Errors never leak internals. Every read that derives a count or a due time takes the API's `now`. Every answer carries `Cache-Control: no-store` and `X-Content-Type-Options: nosniff` (what's answered is the signed-in account's, as things stand now); a file served sets its own year of caching over that, since it never changes under its id. A route that names a deck checks it with the cheap `hasDeck` / `deckTypeId` reads, not by deriving the deck's counts first (which walks every card of it).

**Everything under `/api` but `POST /api/login` and the extension's two (`GET /api/extension`, `GET /api/extension/chrome.zip`: the build Panki carries and its zip, anyone's; "Kept up to date without a store", above) needs a live session**, the app's cookie or the extension's `Authorization: Bearer …`, else `401 { error: { message: "Sign in to continue." } }` (a cookie that names no live session is cleared as it's refused). `session.ts` → `requireSession` looks the cookie's hash up, touches `last_seen_at` at most once a minute, and puts who it is on `res.locals` (`signedIn(res)`, with `admin`); every router takes `dbOf(res)` and reads that account's own database (`app.ts` → `DbOf`), so one account never sees another's rows. **What everyone shares is read by anyone and changed by an admin alone:** the routes marked *admin* below go through `requireAdmin` as well, `403 { error: { message: "Only an admin can change this." } }` for anyone else.
